# Changelog

This changelog tracks changes to the public Sighub documentation in this repository. It does not track the Sighub product itself.

## 2026-08-12

- Updated Marketplace status from "in review" to live in the HubSpot App Marketplace across the public source of truth.
- Added broader category language for HubSpot renewal tracking and HubSpot renewal management.
- Added an observed real-portal example: 24,077 companies scanned, renewal timing found for 95, 5 needing attention, about €35k in contract value, and 0 failed records.
- Refreshed AI/LLM guidance and schema.org structured data to match the current product and Marketplace status.

## 2026-07-01

- Added schema.org JSON-LD structured data (`structured-data/sighub.jsonld`) describing the Sighub organization, the Renewal Radar app with its pricing offers, the website, and an FAQ, with deploy and validation guidance.

- Removed the claim about the origin of the name "Sighub" across all files.
- Added this changelog and last-updated dates for freshness.
