# Ulaş Arslan personal website

Source for the personal website deployed at `https://ulas-arslan.vercel.app`.

## Purpose

The site positions Ulaş Arslan as a product builder and customer-systems operator. Sighub, Speaksee, and LiteBit are used as factual proof points rather than as the entire identity.

## Files

- `index.html` — self-contained website, styles, motion, and structured data
- `llms.txt` — machine-readable profile and viewpoints
- `robots.txt` — crawler rules
- `sitemap.xml` — canonical sitemap
- `vercel.json` — static deployment configuration

## Deployment rule

Use this directory as the root of the single Vercel project named `ulas-arslan`. Do not create extra Vercel projects for normal updates or experiments.
