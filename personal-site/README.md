# Ulaş Arslan personal website

Source and deployment record for `https://ulas-arslan.vercel.app`.

## Positioning

The site positions Ulaş Arslan as a product builder and customer-systems operator. Sighub, Speaksee, and LiteBit are factual proof points rather than the entire identity. The personal brand is intentionally not positioned as a HubSpot specialist.

## Experience source

The complete immersive source is stored in GitHub commit [`7b16cbb`](https://github.com/ulasarslan6262-ui/sighub-public/commit/7b16cbb1e19d3590ef0bb2a30cadf82f3303f3e8), with the cross-scene WebGL layering addition in commit [`62b7ff9`](https://github.com/ulasarslan6262-ui/sighub-public/commit/62b7ff9f21ac96d5f532fdbe39f3123edf20f5b6).

It contains:

- a scroll-driven Three.js world with eight scene-specific formations;
- GSAP and ScrollTrigger motion;
- a cubist editorial art direction;
- responsive desktop and mobile layouts;
- dedicated About and essay pages;
- Person, ProfilePage, SoftwareApplication, and Article structured data;
- `llms.txt`, `robots.txt`, sitemap, favicon, and social artwork.

## Deployment rule

Use only the existing Vercel project named `ulas-arslan`. Do not create extra Vercel projects for previews, tests, diagnostics, or normal updates.
